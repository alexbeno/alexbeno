## Hey, I'm Alexis 👋
 
Product Engineer in Paris. I build AI agents and the interfaces people use to work with them: chat in desktop apps, CLIs, VS Code extensions and web platforms.
 
### Things I've built
 
- **Agent interfaces at [Heal.dev](https://heal.dev)**: an AI QA platform that runs your whole product in a sandbox to find the bugs code review misses. I built an autonomous agent that crawls a product, captures every screen and flags visual bugs, and designed how people work with our agents on desktop, CLI, VS Code and web. Also made the brand and the design system. #4 Product of the Day on Product Hunt.
- **[heal-playwright-tracer](https://github.com/heal-dev/heal-playwright-tracer)**: an open-source, statement-level Playwright tracer built for AI agents.
- **AI proposal writing at Tengo**: interfaces to analyze public tenders and draft answers, used by large companies.
- **[OnlyDust](https://github.com/onlydust-com/saas-frontend)**: 300+ pull requests on a platform that funds open-source contributors. Design system, key product screens built from user interviews, and the back office that sends crypto payouts to contributors.
- **Generative AI back in 2022 at Talk**: caption generation and media planning for social media managers, built with the experts whose know-how we were trying to capture.
- **Freelance**: a logistics SaaS for 4 years, a van conversion brand for 3, React Native apps and 10+ websites.
